# Anira 0.5.0 — Beta

Reproductor integrado de tamaño moderado y ampliación explícita a pantalla completa. Controles directos: pausa, ±10 segundos, posición, anterior/siguiente, velocidad, calidad, bloqueo y ajuste de imagen.

Se retiran las preguntas de marcas del menú. OP/ED utiliza tiempos conocidos cuando corresponda; de lo contrario, permite avanzar 85 segundos con esa acción indicada. No se incluye detección automática de openings/endings.

Se mantienen las listas, el progreso, el carrusel de seis segundos, los respaldos y el ahorro de datos opcional. Firma compatible con las versiones anteriores.

Validación: compilación Android, firma y pruebas de lógica. Pendiente: prueba en hardware Android real. Fuentes externas sujetas a disponibilidad.
